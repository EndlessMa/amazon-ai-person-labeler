## Windows x64 待执行

必须在 Windows 10 22H2 或 Windows 11 x64 主机完成：

```powershell
pnpm install --frozen-lockfile
pnpm check
pnpm dist:win:x64
```

`dist:win:x64` 会先验证当前确为 Windows x64，并确认平台对应的 ExifTool.exe
存在；macOS 无法绕过该门禁生成一个未经验证的 Windows 包。

生成后至少执行以下冒烟验收：

1. 启动 portable `.exe`。
2. 对回归样本运行仅检测，核对已标记、未标记、需规范、近似值、损坏 XMP、
   APNG 和不支持文件的分类。
3. 对一张 PNG 和一张 JPEG 执行添加标签，确认输出图片直接位于批次目录且二次校验通过。
4. 对添加后的图片执行移除标签，确认其他关键词保留。
5. 对 `normal.zip` 和一个 RAR4/RAR5 样本完成预检。
6. 重新生成并核对 `release/release-manifest.json`。

Windows 实机完成上述步骤后，才可把 Windows 状态改为“已验收”。
