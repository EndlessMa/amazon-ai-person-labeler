## macOS Apple Silicon 实包

环境：macOS 26.5.2，arm64。

使用打包后的 `0.1.0-beta.2` `.app` 完成以下真实界面流程：

1. 在系统原生文件选择器中一次选中 7 张图片并导入。
2. 预检正确识别 5 张可处理图片、1 张 APNG 安全跳过和 1 张损坏 XMP 失败。
3. 对 5 张已勾选图片执行添加/规范标签，5/5 均通过处理后二次校验。
4. 本轮改动后的自动化验收确认：文件夹输入输出到
   `images/<输入文件夹>/<相对路径>`；两个文件夹内的同名图片均能处理，且没有
   遗留暂存目录。
5. `report.csv` 的成功输出路径会记录实际分组目录；工具版本为 `0.1.0-beta.2`。
6. 文件夹处理选项左侧已增加说明图标；鼠标悬停或键盘聚焦会显示扫描范围、目录示例、
   输出结构和直接多选图片的说明。在 `1280×720` 与最小 `1080×680` 视口下均无
   截断或工具栏溢出，arm64/x64 实包均已核对包含完整提示文案。
7. ZIP 检测、添加、移除、固定值数量、其他关键词保留和图片载荷不变继续由完整自动化
   回归覆盖；此前实包基线中的相同流程也已通过。

## Windows x64 待执行

必须在 Windows 10 22H2 或 Windows 11 x64 主机完成：

```powershell
pnpm install --frozen-lockfile
pnpm check
pnpm dist:win:x64
```

`dist:win:x64` 会先验证当前确为 Windows x64，并确认平台对应的 ExifTool.exe
存在；macOS 无法绕过该门禁生成一个未经验证的 Windows 包。

生成后至少执行以下冒烟验收：

1. 启动 portable `.exe`。
2. 对回归样本运行仅检测，核对已标记、未标记、需规范、近似值、损坏 XMP、
   APNG 和不支持文件的分类。
3. 对一张 PNG 和一张 JPEG 执行添加标签，确认报告与二次校验通过。
4. 对添加后的图片执行移除标签，确认其他关键词保留。
5. 对 `normal.zip` 和一个 RAR4/RAR5 样本完成预检。
6. 重新生成并核对 `release/release-manifest.json`。

Windows 实机完成上述步骤后，才可把 Windows 状态改为“已验收”。
